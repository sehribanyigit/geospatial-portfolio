# Şehriban Yiğit · Geospatial Portfolio

A portfolio of geospatial analysis, remote sensing, GeoAI, and web mapping projects.

**Live portfolio:** https://sehribanyigit.github.io/geospatial-portfolio/

## Selected work

- **FTW Field Instance Segmentation** — Evaluating a Mask R-CNN baseline across agricultural field morphologies in Spain. [Case study](https://sehribanyigit.github.io/geospatial-portfolio/ftw-field-segmentation.html) · [Project repository](https://github.com/sehribanyigit/ftw-field-segmentation)
- **Adelaide Park Lands Cooling** — Exploring spatial variation in land surface temperature around the Park Lands. [Case study](https://sehribanyigit.github.io/geospatial-portfolio/adelaide-parklands-cooling.html) · [Project repository](https://github.com/sehribanyigit/adelaide-parklands-cooling)
- **Melbourne Essential Services Accessibility** — Mapping access to everyday services across Melbourne. [Case study](https://sehribanyigit.github.io/geospatial-portfolio/melbourne-essential-services-accessibility.html) · [Project repository](https://github.com/sehribanyigit/melbourne-essential-services-accessibility)

The portfolio also includes research on renewable energy potential in Antarctica and smaller technical projects in data pipelines, PostGIS, and web mapping.

## Run locally

From the repository root:

```bash
python -m http.server 8000
```

Open http://localhost:8000/ in a browser. The site uses HTML, CSS, and a small amount of JavaScript; no build step is required.

## Site structure

- `index.html` — homepage
- `ftw-field-segmentation.html`, `adelaide-parklands-cooling.html`, `melbourne-essential-services-accessibility.html` — case studies
- `dist/css/` — styles
- `dist/js/` — scripts
- `dist/assets/` — images and CV
