Melbourne Essential Services Accessibility

How does access to everyday services vary across Greater Melbourne?

Spatial analysis · SA2 · PMTiles · MapLibre GL JS

Explore the live map ↗

The question

Everyday access has a geography.

Grocery stores, healthcare, parks and transit each describe a different part of daily life. I brought these layers together to explore how access differs between Greater Melbourne's SA2 areas.

The map is an exploratory comparison of areas. It does not measure an individual resident's travel time or guarantee access to a service.

01 / Interactive product

Explore the map by area.

The web map brings the spatial analysis into a format that can be explored beyond a static figure.

02 / Approach

From service locations to an area-level view.

I prepared spatial layers for four everyday service categories: groceries, healthcare, parks and transit. The analysis combines these sources at the SA2 level to make patterns across Greater Melbourne easier to compare.

I checked selected areas in QGIS, prepared map-ready data and published an interactive web map. The repository documents the workflow, data sources and scoring choices.

Service layers → Spatial preparation → SA2 comparison → Interactive map

03 / Project outcomes

An analysis you can navigate.

01

Four service lenses

Grocery, healthcare, parks and transit provide complementary views of everyday access.

02

Comparable areas

SA2 geography gives the map a consistent unit for examining variation across the city.

03

Open web map

The result is published as an interactive map so visitors can explore the spatial patterns directly.

04 / Reading the map

A starting point for better questions.

Area-level indicators can highlight differences worth investigating, but they simplify lived access. Boundaries, service quality, capacity and individual travel options are not fully represented by a composite view.

Use the map to explore and compare places, then consult the documented methods before drawing conclusions about a particular neighbourhood.
